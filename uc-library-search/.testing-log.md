## 4. Findings and notes

- Primo display counts are estimates and fluctuate between loads; the skill always presents
  ranges and instructs result scanning rather than exact counts.
- When a missing detail's importance is ambiguous (e.g., material type), the skill errs
  toward a single clarifying question per the 95% confidence principle.
- The "Active filters" heading renders even with no filters applied; harmless UI behavior.
- Full encoding/syntax evidence lives in `references/primo-ve-syntax.md`; output layout in
  `references/response-template.md`.
