Page Layouts

Three layout variants for documentation and tool pages — choose based on how much navigation structure and horizontal space the content needs.

Overview

All three layouts share the same outer shell (dx-doc-layout + dx-header) and differ only in how dx-doc-body is configured. A modifier class controls whether the sidebar column appears and whether a max-width constraint is applied to the content area.

Sidebar

Two-column layout with a sticky left sidebar for page navigation. Best for multi-section documentation and reference pages.

No sidebar

Single-column layout with centered, max-width-constrained content. Best for focused tools, forms, and single-purpose pages.

No sidebar — wide

Single-column layout with no max-width constraint. Best for dashboards, wide data tables, and tools that need full horizontal space.

Sidebar layout

The default layout. Produces a two-column grid: a var(--sidebar-w) wide left column for navigation and a flexible right column for content. The sidebar column disappears on narrow viewports (≤ 768px).

The content column inherits the outer max-width: var(--doc-max) constraint and is centered with margin: 0 auto.

<div class="dx-doc-body">
  <!-- sidebar -->
  <nav class="dx-sidebar" aria-label="Page sections">
    <div class="dx-sidebar-section">
      <span class="dx-sidebar-label">On this page</span>
      <ul class="dx-sidebar-nav">
        <li><a href="#section">Section</a></li>
      </ul>
    </div>
  </nav>

  <!-- main content -->
  <main id="main" class="dx-main">
    ...
  </main>
</div>

No sidebar

Add the dx-doc-body--no-sidebar modifier and omit the <nav class="dx-sidebar"> element entirely. The content column takes up the full grid width but is still constrained by max-width: var(--doc-max) and centered.

Best for focused pages where section-level navigation would be redundant — forms, settings, creation flows, and single-purpose tools.

<div class="dx-doc-body dx-doc-body--no-sidebar">

  <!-- No <nav class="dx-sidebar"> element -->

  <main id="main" class="dx-main">
    ...
  </main>
</div>

No sidebar — wide

Add the dx-doc-body--no-sidebar-wide modifier and omit the sidebar. This overrides max-width to none, allowing the content column to expand to the full viewport width minus the outer padding.

Best for dashboards, data tables with many columns, tools that render a canvas or preview at full width, and any context where the centered reading-width constraint actively hurts the layout.

Content max-width still applies inside sections
The layout itself is unconstrained, but dx-main prose content like <p> and <h2> still have a max-width set in frame.css. Wide layouts are most effective when you're placing custom components (tables, canvases, panels) that opt out of that prose constraint.
<div class="dx-doc-body dx-doc-body--no-sidebar-wide">

  <!-- No <nav class="dx-sidebar"> element -->

  <main id="main" class="dx-main">
    ...
  </main>
</div>

When to use each

Layout Use when… Avoid when…
Sidebar The page has 3+ named sections worth navigating to; users will scan and jump between them. Documentation, reference pages, multi-step guides. The page has a single flow and the sidebar would just be visual noise — forms, focused tools, checkout-style flows.
No sidebar Content is a single continuous flow; the reading-width constraint (var(--doc-max)) actually helps legibility. Focused tools, settings pages, creation wizards. The page has many sections that benefit from quick navigation, or the content (tables, canvases) is hurt by the width constraint.
No sidebar — wide The primary content is data-heavy (wide tables, dashboards) or spatial (canvas, map, diagram). Every pixel of horizontal space has a purpose. The primary content is prose — long text at full viewport width is hard to read. Also avoid for pages with only a small amount of content.

CSS reference

All layout classes live in css/frame.css. Apply modifier classes to the dx-doc-body element.

  • class="dx-doc-body" Default sidebar layout. Two-column grid: var(--sidebar-w) left + flexible right. Max-width: var(--doc-max), centered.
  • class="dx-doc-body dx-doc-body--no-sidebar" Single-column layout. Max-width: var(--doc-max), centered. Omit the sidebar <nav>.
  • class="dx-doc-body dx-doc-body--no-sidebar-wide" Single-column layout. No max-width — content fills the full available width. Omit the sidebar <nav>.
