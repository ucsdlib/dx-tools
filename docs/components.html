Design system

Components

Every component meets the 44 px touch target minimum. Tactile button press is implemented via translateY + box-shadow. No AI design tells — full borders, no left-only accent stripes.

Buttons

Four variants, three sizes. The press feel comes from a bottom-edge shadow that collapses on :active with a 2px downward translate. Disabled state uses opacity — never a grey color swap.

Alerts

All alerts use icon + color + text. Never color alone. Use role="alert" for urgent messages; role="status" for informational notices.

Information
This is an informational message. Use role="status" for non-urgent notices.
Success
Action completed successfully. The change has been saved.
Warning
This action may have unintended effects. Review carefully before proceeding.
Error
Something went wrong. Please try again or contact support.

Panels

Featured panels use a top accent stripe — not a left border. This is a deliberate design decision: left-border cards are an AI design tell. A top stripe conveys importance without sacrificing the panel's visual integrity.

Standard panel

A neutral container for grouped content. Use for settings, configuration blocks, and content groups.

Raised panel

Elevated
Slightly elevated above the standard panel. Use for interactive cards or when visual hierarchy needs reinforcement.

Featured — accent stripe (top)

Primary
The accent stripe runs along the top edge — never just the left side. Signals importance or a highlighted state.

Featured — success

Use success stripe for completed steps, confirmed states, or positive outcomes.

Featured — danger

Use danger stripe for errors, blocked states, or items requiring immediate attention.

Tables

Wrap in .table-wrap for overflow and border. Use .table--striped for zebra rows on dense data.

Tabs

Use role="tablist", role="tab", role="tabpanel", and aria-selected. Keyboard: arrow keys move between tabs, Enter/Space activates.

The Overview tab is active. Tabs use an underline indicator on the active tab — not a filled background.

Images

All images must have meaningful alt text. Decorative images use alt="". Use <figure> + <figcaption> when the image requires a visible caption.

Responsive image

html
<img
  src="photo.jpg"
  alt="Descriptive alt text — who, what, where"
  class="img-responsive"
  width="800"
  height="400"
  loading="lazy"
>

</div>

Dialogs

Use the native <dialog> element. Focus must be trapped inside the dialog while open. Pressing Escape closes it. The first focusable element inside receives focus on open.

Confirm action

Are you sure you want to proceed? This will save the current state and cannot be undone.

Code display

Inline code

Use --color-accent for interactive elements and --color-focus for the focus ring. The Tab key moves focus; Enter activates buttons.
