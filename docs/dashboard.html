Design system

Dashboard

Patterns for presenting data, metrics, and status at a glance. Stat cards use full borders — never left-border-only. All numeric values use tabular-nums for aligned scanning. Trends always include text, never just arrows.

Stat cards

Three elements: label (uppercase, small), value (large, bold, tabular-nums), trend (icon + numeric change + direction text). Full border — never left-only.

Chart containers

The design system provides styled containers and accessibility requirements — teams supply their own charting library (Chart.js, D3, Vega, etc.). Charts must provide a data table or text alternative for screen reader users.

Data tables

For dense data, use .table--striped. Numeric columns right-align with font-variant-numeric: tabular-nums for clean scanning. Provide a caption or aria-label on every table.
