Design system

Typography

Three typefaces, three distinct jobs. Tool chrome uses Atkinson Hyperlegible — purpose-built for low-vision legibility. Preview areas use Roboto, UC San Diego's free web substitute. Code uses JetBrains Mono.

Frame font — Atkinson Hyperlegible

Designed by the Braille Institute specifically for low-vision readers. Every letterform is engineered for maximum distinguishability — the 1, l, and I look nothing alike. Ideal for tool interfaces where every character must be read accurately.

Code font — JetBrains Mono

A monospace typeface designed specifically for developers, with increased letter height, wider characters, and ligature support for common programming symbols. Used in code blocks, terminals, and any monospaced data display.

Type scale

Tool interfaces run larger than marketing defaults. The minimum body size is 16px; the minimum for any rendered text is 14px (--text-sm). Sub-12px text is prohibited.

Font weights

Atkinson Hyperlegible provides Regular (400) and Bold (700). Intermediate weights (500, 600) render as 400 on this typeface — use sparingly and test. Roboto and JetBrains Mono have full weight ranges.

400 · Regular
Body copy, default weight
500 · Medium
Navigation links, subtle emphasis
600 · Semibold
Form labels, card titles, sidebar nav active
700 · Bold
Page headings, button labels, stat values

Heading hierarchy

Use semantic HTML heading levels (<h1>–<h4>) and apply size via CSS. Never skip levels for visual effect — skipping breaks screen reader navigation.

H1 · Display heading (36px Bold) — one per page

Lead text sits below the page title. It uses --text-md at 18px with muted color.

H2 · Page section (28px Bold) — major topic breaks

Body copy at 16px. Atkinson Hyperlegible's generous letter-spacing makes dense paragraphs readable at this size without adjustment.

H3 · Subsection (22px Semibold)

Use h3 for groups within a section. Avoid more than two levels of nesting in most tool interfaces.

H4 · Panel or card title (18px Semibold)

Used inside cards, sidebar sections, and form fieldsets. Below h4, use bold body text rather than heading elements.
