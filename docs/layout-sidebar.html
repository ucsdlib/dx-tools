Sidebar layout

This page uses the default dx-doc-body layout — a two-column grid with a sticky sidebar for section navigation and a max-width-constrained content area.

About this layout

You are viewing the sidebar layout demo
The sidebar on the left is part of this layout. Content is centered with a max-width constraint. Use this layout for documentation, reference pages, and any multi-section content where in-page navigation adds value.

The sidebar layout is the design system's default. It places a var(--sidebar-w) wide navigation column to the left of the main content. On viewports narrower than 768px, the sidebar collapses and the layout becomes single-column.

The content area honors max-width: var(--doc-max) — content stays readable and doesn't stretch uncomfortably wide on large monitors.

Components in context

Standard components work at home in this layout. Panels, tables, and form groups all sit comfortably within the constrained reading width.

Example panel

Active

Panels group related controls or information. The sidebar layout's max-width constraint means panels never grow wider than a comfortable reading measure.

Property Value Notes
grid-template-columns var(--sidebar-w) 1fr Two columns: fixed sidebar + flexible main
max-width var(--doc-max) Centered; constrains overall layout width
Responsive breakpoint 768px Sidebar collapses; single-column below this

When to use this layout

The sidebar layout is appropriate when:

  • The page has three or more named sections that users will want to navigate between directly
  • Content is primarily prose and benefits from a readable line length (the max-width constraint helps here)
  • You want consistent visual structure across a family of related pages

Consider a different layout when the page has a single continuous flow, or when the content (a wide table, a canvas, a preview frame) is hurt by the width constraint.

All DX Tools documentation pages use this layout
Every page in the design system docs — including this one — uses the default sidebar layout.
