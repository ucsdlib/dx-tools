Design system

Forms

All form elements have a 44 px minimum height and 16 px font size. No floating labels. Error states use icon + color + text — never color alone. Labels are always visible, never placeholder-only.

Principles

  • Always-visible labels — Never use placeholder text as the sole label. Placeholders disappear on input and are not read reliably by screen readers.
  • No floating labels — Floating labels create focus management complexity and fail reliably with autofill. Use a standard label above the input.
  • Error = icon + color + text — A red border alone fails WCAG 1.4.1. Always include an error message below the field and an error icon.
  • Helper text is permanent — Don't hide helper text on error. Show both the hint and the error message so context isn't lost.
  • 44 px touch targets — All inputs, checkboxes, radios, and toggles meet WCAG 2.5.5 minimum.
  • Group with fieldset/legend — Checkbox groups and radio groups use <fieldset> + <legend> so screen readers announce the group name.

html
<div class="form-group">
  <label class="form-label" for="email">
    Email address
    <span class="required" aria-label="required">*</span>
  </label>
  <input
    class="form-input"
    type="email"
    id="email"
    name="email"
    autocomplete="email"
    required
    aria-required="true"
    aria-describedby="email-hint"
  >
  <span class="form-hint" id="email-hint">Use your @ucsd.edu address.</span>
</div>

Toggle switches

Use for binary on/off settings that take immediate effect — not for form submission choices (use a checkbox instead).

html
<label class="toggle">
  <input
    class="toggle__input"
    type="checkbox"
    role="switch"
    aria-checked="true"
    checked
  >
  <span class="toggle__track" aria-hidden="true">
    <span class="toggle__thumb"></span>
  </span>
  <span class="toggle__label">Enable live preview</span>
</label>

Validation states

Error states use .form-group--error on the wrapper, plus a .form-error element. The input uses aria-describedby to associate the error message.

Enter your @ucsd.edu address. Enter a valid email address.
Username is available.
html
<div class="form-group form-group--error">
  <label class="form-label" for="email">Email</label>
  <input
    class="form-input"
    type="email"
    id="email"
    aria-invalid="true"
    aria-describedby="email-hint email-error"
  >
  <span class="form-hint" id="email-hint">Your @ucsd.edu address.</span>
  <span class="form-error" id="email-error" role="alert">
    Enter a valid email address.
  </span>
</div>
