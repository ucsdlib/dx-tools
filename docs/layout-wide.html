Wide layout

This page uses dx-doc-body--no-sidebar-wide — no sidebar and no max-width constraint. Content expands to the full available viewport width, making it ideal for dashboards and data-heavy tools.

About this layout

The wide layout removes both the sidebar column and the outer max-width constraint. The dx-doc-body--no-sidebar-wide modifier sets max-width: none, so the content pane grows to fill whatever space the viewport provides.

This is the right choice when the tool's primary content — a data table, a canvas, a sitemap diagram — actively benefits from every available pixel of horizontal space. Use it sparingly; prose text at full viewport width is uncomfortable to read.
