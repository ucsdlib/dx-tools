No sidebar layout

This page uses dx-doc-body--no-sidebar — a single-column layout with no sidebar nav. Content is still constrained by max-width: var(--doc-max) and centered on the page.

You are viewing the no-sidebar layout demo
There is no sidebar column on this page. The content takes up the full grid width, centered within var(--doc-max). Compare this to the sidebar demo and the wide demo.

About this layout

The no-sidebar layout removes the left navigation column entirely. The modifier class dx-doc-body--no-sidebar collapses the grid to a single column. The outer max-width constraint is preserved — content stays readable without sprawling.

This layout works well for pages that have a clear beginning-to-end flow: settings forms, creation wizards, onboarding pages, and any focused tool where sidebar navigation would just be visual noise.

Because the sidebar is absent, page-level navigation (if needed) should be placed inline — for example, a breadcrumb trail or a prev/next footer with links to related pages.

Sample: Settings form

A focused settings form is a natural fit for the no-sidebar layout. The content is a single continuous flow; the max-width constraint keeps line lengths comfortable.
